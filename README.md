# 🏨 Hotel Booking Cancellation Prediction App

**🔍 Description**

This is a Streamlit web app that predicts whether a hotel booking will be canceled based on input features such as booking dates, guest information, and reservation details. The prediction is powered by a Random Forest Classifier trained on real-world hotel booking data.
---
🚀 Deployed using Streamlit | 🧠 Model: Random Forest Classifier
